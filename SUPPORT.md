# Getting help

Remyral is a community-supported open-source project. Please pick the channel that fits your request:

| You want to… | Go to |
| --- | --- |
| Ask how to install, configure or use Remyral | [Discussions → Q&A](https://github.com/dotKa/remyral/discussions/categories/q-a) |
| Suggest or discuss an idea | [Discussions → Ideas](https://github.com/dotKa/remyral/discussions/categories/ideas) |
| Report a bug, a documentation problem or a concrete feature request | [Issues](https://github.com/dotKa/remyral/issues/new/choose) (use the forms) |
| Report a security vulnerability | **Privately**, as described in [SECURITY.md](SECURITY.md) — never in a public issue or discussion |
| Anything else (conduct reports, press, licensing, trademarks) | info@remyral.com |

Before you ask, the [README](README.md) and the documentation map it links to, the operator guides in
[docs/ops/](docs/ops/) and the [existing issues](https://github.com/dotKa/remyral/issues) answer many questions.

When you report a problem, include the Remyral version (console → System status, or `sudo remyral-ctl status`),
the worker version (`remyral-worker doctor`), the worker's operating system and architecture, and the AI runtime and
its version. Redact host names, IP addresses, tokens, e-mail addresses and other personal data from logs and
diagnostics before you paste them.

## Response times

Help is given on a best-effort basis by the maintainers and the community. There is no paid support and no service
level agreement (SLA). Security reports are handled as described in [SECURITY.md](SECURITY.md).

Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md).
