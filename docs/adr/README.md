# Architecture Decision Records

One file per consequential decision, numbered `NNNN-kebab-title.md`, using [template.md](template.md).

Statuses: `Proposed` → `Accepted` (human sign-off, recorded with name and date) → optionally `Superseded by ADR-NNNN` / `Deprecated`. An ADR is never edited after acceptance except to change its status; a new ADR supersedes it.

ADRs 0002–0013 were accepted together at the P0 sign-off. ADR-0007 and ADR-0012 are refined after hands-on tests.

The P0 gate requires every ADR below to be `Accepted` or explicitly deferred with a ticket.
