# Design notes

The files in this directory are the historical working notes of the design process: one note per backlog task
(`p<phase>-<name>`), written while that task was designed and built. A note records the problem as it was seen at the
time, the options considered, what was decided and what was left unverified. "This task" in a note means the backlog
task the note belongs to.

They are kept for their reasoning, not as a description of the current system. A note may reference screens, files,
settings or behaviour that were changed or removed later, and it is not updated when that happens.

For the current state, these are authoritative:

- the architecture decision records in [docs/adr/](../adr/README.md);
- the runbooks and operator guides in [docs/ops/](../ops/);
- the security documents in [docs/security/](../security/).

When a note and one of those disagree, the ADR or the runbook is right.
